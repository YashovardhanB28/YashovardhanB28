# Contributing

This is a personal profile repository, so contributions are welcome but limited in scope:

- **Typos / broken links:** open a PR directly, happy to merge.
- **Suggestions on research write-ups:** open an issue using the "Feedback" template — especially
  useful from anyone with domain expertise in genomics/oncology/ML who spots something worth
  correcting or clarifying.
- **Feature ideas for the automation/tooling:** open an issue using the "Idea" template. Please
  check `docs/ARCHITECTURE.md` first — some features were considered and deliberately deferred,
  with reasoning included there.

There's no CLA or formal review process — this isn't a library other projects depend on.
